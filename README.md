# Manuscript

This repository contains the data and code used to generate the figures for the manuscript.

## Installation

1. Clone the repository.
2. Create/activate a Python environment.
3. Install the dependencies: `pip install -r requirements.txt`

## Usage

Command Line
To generate figures directly from the terminal:

```bash
python ./code/generate-figures.py
```

## Repository Structure

- `code/` – scripts and notebooks for figure generation
- `data/` – datasets used in the manuscript
- `figures/` – generated figures
